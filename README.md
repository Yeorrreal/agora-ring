# 아고라 링

철학자들이 서성이는 아고라에서, 서로 맞서는 명제를 말하는 사람들을 링에 올려 싸움을 붙이고 키워드를 모으는 16비트 픽셀아트 추리 퍼즐. 지금은 1장 '근원(아르케)'까지 플레이할 수 있다.

**플레이**: https://yeorrreal.github.io/agora-ring/

- 철학자를 누르면 명제가 말풍선으로 뜨고, 계속 누르면 다른 명제로 바뀐다.
- 맞서는 명제를 띄운 사람들을 링으로 끌어다 놓고 종을 친다.
- 델포이의 신녀는 신탁(힌트)을 내리고, 콩밭에서는 오볼을 벌고, 물장수에게서는 물시계를 채운다.

## 빌드

```bash
npm install galmuri@2.39.3
python3 build.py
```

`agora-ring.src.html`이 소스이고, `build.py`가 Galmuri11 폰트를 넣어서 `index.html`을 만든다.
